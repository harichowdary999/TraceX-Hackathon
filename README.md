# TraceX-Hackathon
 Problem Statement 4: APK Provenance & Fraud Intelligence Platform
Title: Tracing the Source and Spread of Fraudulent APKs
Challenge:
Law enforcement and financial institutions struggle to trace where fraudulent APKs originate and how they propagate.
Build a platform that:
•	Extracts APK metadata (certificates, package names, embedded URLs)
•	Maps relationships between APKs, domains, IPs, and certificates
•	Visualizes a network graph of fraud infrastructure
•	Helps identify “root” sources or repeat offenders
